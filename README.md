# GCP Terraform Deployment Project

This project aims to automate the deployment and testing of infrastructure on Google Cloud Platform (GCP) using Terraform and GitHub Actions. The primary goal is to streamline the deployment process, generate documentation, and perform automated testing using AI-powered tools.

## Key Technologies
- **Terraform:** Used for defining infrastructure as code for GCP, such as creating a Google Cloud Run service and a Cloud Storage bucket.
- **GitHub Actions:** Facilitates CI/CD workflows to automate the deployment process upon each push to the main branch.
- **Google Cloud SDK (gcloud):** Integrates with GCP resources and manages deployment credentials.
- **Playwright & Node.js:** Used to conduct web application testing by generating and running tests programmatically.
- **OpenAI API:** Assists in generating documentation and test scripts using AI.
- **SendGrid:** Sends test result notifications via email.
- **Google Cloud Storage:** Stores outputs such as AI-generated test scripts and screenshots.

## High-Level Workflow

1. **Triggering:** The workflow is triggered by a push to the main branch of the repository.
   
2. **Dependency Installation:** The workflow sets up the necessary environment for running Terraform and Node.js scripts.

3. **Terraform Operations:**
   - Variables are extracted to determine whether to apply or destroy the infrastructure based on repository configuration.
   - Terraform is initialized, and commands (`apply` or `destroy`) are executed to manage GCP resources.
   - The infrastructure includes a Cloud Run service, storage buckets, and appropriate IAM configurations.

4. **Documentation Generation:** 
   - Terraform state and configuration are converted into documentation using AI-powered tools.

5. **Web Application Testing:**
   - A Playwright test script is generated by OpenAI and executed to verify application deployment.
   - Screenshots and logs are captured during test execution.

6. **Results and Reporting:**
   - Test results, logs, and screenshots are uploaded to Google Cloud Storage.
   - An email summarizing the test results, including links to generated scripts and application URLs, is sent to configured recipients.

This automated setup provides a seamless infrastructure management flow, integrates development and operations processes, and leverages cutting-edge AI for enhancing operational productivity.
